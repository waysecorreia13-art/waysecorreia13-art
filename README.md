### 🧭 Como eu trabalho

- **Um número, uma verdade.** Todo número que eu entrego vem com a fonte, o filtro e o período, e é
  conferido com o indicador oficial.
- **Homologação antes da produção.** Página nova nasce e é testada num servidor de teste; só depois vai
  para o portal que a empresa usa.
- **Banco de produção só para leitura.** A análise consulta; quem grava é o sistema.
- **Dado pessoal no mínimo.** Sigo a LGPD: o total antes do nome, e o nome só quando a decisão pede.
- **IA com revisão humana.** Uso o Claude Code como par de programação; a IA propõe, eu confiro e
  respondo pelo resultado.
